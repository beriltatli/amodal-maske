What this result means

The network receives masks of the target and occluding objects. The photograph is used for display; this model does not detect objects from RGB.

Amber marks pixels beyond the visible input. A completion can add incorrect pixels or remove visible pixels. Both are measured, and the raw prediction is shown without manual correction.

IoU measures overlap with the reference (higher is better). The visible-only baseline measures the same overlap before completion. These are bundled demo images, not a held-out benchmark.
